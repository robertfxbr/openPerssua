# Plano de ferramentas MCP

Objetivo: consultar ferramentas MCP nas perguntas manuais e sobre a tela, preservando os sete itens de assistentes v2.

Arquitetura definida pelo pedido: cliente JSON-RPC próprio em `electron/mcp/`, transportes stdio e Streamable HTTP, sem dependências novas. Gerenciador guarda configuração separada dos assistentes, cifra ambiente/cabeçalhos com safeStorage e aplica permissões no main. Orquestrador usa o router existente em três etapas JSON, até três chamadas em 60 segundos; a resposta usa o builder atual. Interface compacta com confirmação explícita e seleção por assistente, inicialmente vazia.

- [x] Cliente e servidor de teste: inicialização, paginação, JSON/SSE, sessão, cancelamento, timeouts, morte, reinício, stderr volumoso e comandos Windows.
- [x] Gerenciador e orquestrador: armazenamento cifrado, importação validada, schema básico, política revalidada após confirmação; testes com provedor falso e limites.
- [x] Integração IPC e React: configurações, editor de assistente, confirmações e indicação das ferramentas usadas; auto-assist fora do caminho MCP.
- [x] Documentação e validação: build, testes novos e suíte de assistentes; commits pequenos em PT-BR com identidade pedida.

Restrições: nenhuma chamada a modelo real nos testes; não acessar produto proprietário; não alterar versão, autoria, licença ou créditos; não encerrar instâncias do usuário; não publicar.

Revisão: segredos ausentes no renderer/export, delimitadores escapados, cancelamento durante confirmação/conexão, política alterada durante uma chamada e isolamento entre streams.

Evidências: `npm run build`, `npm run test:mcp` (5 scripts) e `npm run test:assistants` (8 scripts), todos aprovados. A interface foi exercitada em Electron com preload real, safeStorage do Windows, servidor Node local e imagens fictícias; sem modelos reais. Corrigido bloqueio anterior de miniaturas data: na CSP. Inspeção visual em janela de 420 px.

Limites da validação: não testado com servidores externos ou modelos reais; JSON Schema tem somente validação básica, não resolução de referências ou todas as palavras-chave da especificação.
